---
title: 企业微信
description: 把企业微信智能机器人接入 OpenBee。
---

插件 ID `wecom`。Bee 回复单聊和群里的 @。

## 1. 创建机器人

在企业微信管理后台打开 **智能机器人**，选择 **API 模式创建**，连接方式选 **长连接**，复制 **Bot ID** 和 **Secret**。

## 2. 接入 OpenBee

在 **设置 → 插件 → 插件市场** 里安装 **企业微信**，填好以下配置并启用：

| 配置项 | 填写 |
| --- | --- |
| Bot ID、Secret | 第 1 步获取 |
| 机器人名称 | 机器人在企业微信里的名字 |

一个机器人只能接一台 OpenBee，另一台用同一个机器人会把它接管过去。机器人发送的文件上限 20 MB。
