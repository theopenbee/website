title: 微信
description: 扫码把微信接入 OpenBee。
---

插件 ID `weixin`。Bee 只回复单聊，不需要开发者账号。

## 接入 OpenBee

1. 在 **设置 → 插件 → 插件市场** 里安装 **微信**。
2. 在插件页面开始 **微信扫码登录**，用微信扫码并在手机上确认。微信显示数字时，把它输进去。
3. 启用插件。

命令行里 `openbee plugin configure weixin` 也能扫码登录，请在运行 OpenBee 的机器上执行。

## 限制

- **你每发一条消息，微信最多允许机器人回复 10 条。** 长回复会拆成多条，定时任务的结果也算在内。超出后发送会失败，直到你再发一条消息。
- 登录过期后，在插件页面重新扫码即可。
