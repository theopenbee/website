OpenBee 把你已经在用的 Agent CLI（Claude Code、Codex 或 pi）变成一支 7×24 小时在线的数字员工团队。你给协调者 Bee 发消息，Bee 把每件活派给合适的员工。

## 概念

- **Bee：** 你对话的协调者，可以在桌面版、浏览器或聊天软件里找它。
- **员工：** 一个 Agent CLI，有自己的引擎、目录和规则。
- **任务：** 交给一个员工的一件活，可以立即、延时或周期执行。

## 准备

一个已安装并登录的 Agent CLI。OpenBee 本身不带模型，数据保存在 `~/.openbee`。
