---
title: 聊天命令
description: 停止工作、重置上下文、查看状态和切换引擎的斜杠命令。
---

所有聊天软件、桌面版和 Web 控制台都能用。命令要单独作为一条消息发送。

| 命令 | 作用 |
| --- | --- |
| `/stop` | 停止 Bee 在这个对话里正在进行的回复。 |
| `/stop <员工名>` | 停止该员工在这个对话里的任务，保留上下文。 |
| `/clear` | 重置这个对话里 Bee 和所有员工的上下文。 |
| `/clear <员工名>` | 重置这个对话里某个员工的上下文。 |
| `/status` | 查看活跃的上下文和正在运行的任务。 |
| `/list [关键词]` | 列出员工，关键词按描述筛选。 |
| `/engine <引擎>` | 设置默认引擎：`claude`、`codex` 或 `pi`。 |
| `/engine <引擎> <员工名>` | 设置某个员工的引擎。 |

## 说明

- 有任务在运行时，`/clear` 需要确认：30 秒内再发一次。定时任务会保留。
- `/engine` 要等没有任务运行时才能切换。
- 在员工自己的对话里，`/stop` 和 `/clear` 只作用于这个员工。
- 群聊里 `@机器人 /status` 也有效。
- Telegram 另有 `/auth <授权码>`，见 [Telegram](/zh/docs/chat-apps/telegram/)。
