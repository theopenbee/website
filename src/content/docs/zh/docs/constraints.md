---
title: 工作约束
description: 员工在每次对话中都遵守的长期规则。
---

工作约束是员工的长期规则：怎么称呼你、能做什么、做到什么程度算完成。员工在每次对话开始时都会收到。

## 设置

- **新建员工时：** **高级配置 → 工作约束**。
- **已有员工：** 员工资料 → **约束** → **编辑工作约束**，有三个模板可以参考。
- **通过 Bee：** “告诉 Maya 不要直接推送到 main。”

## 示例

```text
【工作范围】
- 允许：在 ~/code/api 里修 bug、补测试。
- 禁止：删除数据、推送到 main、未经确认对外发布。

【交付规范】
- 汇报完成前先跑测试，并说明是否通过。
```

规则要短而具体。员工负责什么写在描述里。

## 何时生效

从下一次对话开始。在员工对话里点 **新对话**，或在聊天软件里发送 `/clear <员工名>`。定时任务在下一次运行时生效。

## Bee 的记忆

Bee 还会记住你告诉它的偏好，例如“记住，总结都用中文写”。想让它忘掉，也直接说。
