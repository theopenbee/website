---
title: 任务
description: 立即、延时或周期执行任务，以及如何停止和取消。
---

告诉 Bee 要做什么，Bee 会创建任务并挑选员工。

| 类型 | 示例 |
| --- | --- |
| 立即 | “修复登录跳转的 bug。” |
| 定时一次 | “30 分钟后检查部署有没有完成。” |
| 周期任务 | “每个工作日 9:00，总结昨天的提交。” |

周期任务按 cron 周期执行，使用服务器的时区，直到你取消。

## 结果

- **聊天软件：** 回到同一个对话，开头带上员工名字。
- **桌面版和 Web 控制台：** 在员工自己的对话里，从 Bee 的交接卡片点进去。

失败和取消也会在同一个地方通知。失败的任务不会自动重试。

## 排队与限制

- 一个员工同一时间只做一个任务，其余排队。不同员工并行。
- 员工单次运行最长 24 小时，Bee 最长 10 分钟。在 `~/.openbee/config.yaml` 里修改 `bee.engine.timeout.worker` 和 `bee.engine.timeout.bee`，然后执行 `openbee restart`。
- 立即执行的任务会接着员工在该对话里的上下文；定时一次和周期任务每次都从头开始。
- 重启后，没跑完的任务会重新运行。

## 停止与取消

| 想要 | 操作 |
| --- | --- |
| 停止当前工作 | 员工对话里的 **停止**，或 `/stop <员工名>` |
| 取消定时任务 | 跟 Bee 说：“取消每天的提交总结。” |
| 查看定时任务 | 问 Bee：“我有哪些周期任务？” |
| 重新开始 | **新对话** 或 `/clear`，定时任务保留 |
