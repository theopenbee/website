OpenBee turns the agent CLI you already use (Claude Code, Codex or pi) into a team of always-on workers. You message Bee, the coordinator, and Bee hands each job to the right worker.

## Concepts

- **Bee:** the coordinator you talk to, from the desktop app, the browser or a chat app.
- **Worker:** an agent CLI with its own engine, folder and rules.
- **Task:** one job for one worker, run now, later or on a schedule.

## Requirements

One agent CLI, installed and signed in. OpenBee ships no model. Your data stays in `~/.openbee`.
